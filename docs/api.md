# API

OpenAPI is generated by Quarkus SmallRye OpenAPI.

Run the app and open:

```text
http://localhost:8080/api/docs
```

The OpenAPI document is available at:

```text
http://localhost:8080/api/openapi
```

## Authentication

The application supports:

- Basic Auth for browser/UI and ordinary REST API access.
- API tokens for `/api/agent` automation.

Default local credentials:

```text
Basic Auth: admin / admin
Agent token: yac4e-dev-agent-token
```

Agent token scopes:

- `agent:read`
- `model:propose`
- `model:write`

## Agent Proposal API

External agents inspect source code outside YaC4e and submit evidence-backed architecture proposals:

```http
GET  /api/agent/workspaces/{workspaceId}/proposals
POST /api/agent/workspaces/{workspaceId}/proposals
POST /api/agent/workspaces/{workspaceId}/proposals/validate
GET  /api/agent/workspaces/{workspaceId}/proposals/{proposalId}
POST /api/agent/workspaces/{workspaceId}/proposals/{proposalId}/apply
POST /api/agent/workspaces/{workspaceId}/proposals/{proposalId}/reject
```

Supported proposal actions:

- `CREATE_ELEMENT`
- `UPDATE_ELEMENT`
- `CREATE_RELATIONSHIP`
- `UPDATE_RELATIONSHIP`
- `CREATE_LINK`
- `CREATE_METADATA_DEFINITION`
- `CREATE_VIEW`
